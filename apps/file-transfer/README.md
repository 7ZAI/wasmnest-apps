# File Transfer（`com.wasmnest.file-transfer`）

内网文件传输：设备发现、首连确认、文件浏览、任务队列与断点续传。桌面为服务端（共享目录），移动端可浏览、下载与上传，双向传输。

支持端：桌面 + 移动

## 功能特性

### 桌面（服务端）

- **设备发现**：在线对端自动发现与切换，首连确认建立信任
- **远程目录浏览**：浏览对端共享目录，多任务并发传输
- **传输队列**：暂停 / 恢复 / 断点续传 / 失败重试
- **共享目录**：本地目录挂载供对端访问

### 移动（对端）

- **双向传输**：浏览桌面端共享目录，多选批量下载到手机；手机文件经共享目录上传到桌面端
- **传输队列**：暂停 / 恢复 / 取消 / 重试，失败原因明示
- **接收策略**：逐批批准 / 自动接受 / 自动拒绝，可设批准超时
- **保存到…**：长按文件自选保存位置（系统对话框）
- **历史记录**：打开所在文件夹、清空记录

## 使用方式

桌面：侧边栏「文件传输」→ 选择在线对端 → 浏览远程文件 → 加入传输队列；下载目录与并发数在设置面板调整。

移动：两端连接后先在桌面端开启共享目录，即可在文件传输页浏览、下载或上传；队列面板分「全部 / 发送 / 接收 / 历史」查看进度与记录。
