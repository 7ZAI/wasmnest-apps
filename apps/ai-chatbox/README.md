# AI Chatbox（`com.wasmnest.ai-chatbox`）

AI 大模型对话：接入任意 OpenAI 兼容 / Anthropic / Gemini 供应商，流式对话、多会话管理、对话日志可追溯。桌面与移动双端可用。

支持端：桌面（宿主侧边栏「AI 对话」）/ 移动（宿主壳应用列表「AI Chatbox」）

## 功能特性

- **多供应商**：OpenAI / Anthropic / Gemini / 自定义（OpenAI 兼容），Base URL、API Key、模型均可配置
- **流式对话**：实时流式输出，思考模式与推理强度可调
- **应用设置**：代码渲染（字体大小 / 行距 / 高亮主题）、思考模式、限流重试均在应用内「设置」中调整；设置页同时展示已配置供应商（可折叠，点行编辑）并提供「添加供应商」入口
- **会话管理**：多会话保存 / 恢复 / 删除，自由切换供应商与模型
- **对话日志**：JSONL 落盘，可追溯审计
- **渲染**：Markdown + 代码高亮

## 使用方式

桌面：侧边栏「AI 对话」→ 标题栏齿轮按钮「设置」中配置供应商（设置页内「已配置的供应商」可折叠查看，点「添加供应商」直达模板选择，点已配置供应商行进入编辑 / 删除）→ 新建对话开始提问；对话自动保存，可在会话列表切换 / 删除。设置页下方可直接调整代码渲染、思考模式与限流重试。

移动：宿主壳应用列表打开「AI Chatbox」独立页面；首次使用先在应用内配置供应商与模型，随后即可开始聊天。
