# Changelog

本文件记录 **烂笔头（Lanbitou）**（`com.wasmnest.lanbitou`）的版本变更。

- 版本真源：`apps/lanbitou/desktop/plugin.json` 的 `version`。
- 发布 tag：`lanbitou-v<X.Y.Z>`；发布流程见 [`docs/CI.md`](../../docs/CI.md) §2。
- 当前 `0.0.1` 为开发版本，尚未发布（没有 `lanbitou-v0.0.1` tag）。
- 结构参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号遵循 [Semantic Versioning](https://semver.org/lang/zh-CN/)。
- 发布时把 `[Unreleased]` 收为 `## [<version>] - <YYYY-MM-DD>`，与版本号、tag 同一批提交。

## [Unreleased]

### 新增

- 首个桌面应用：轻量级 Markdown 记事本，纯文本编辑 + 实时预览。
- 临时记事（默认文档）：固定 id `scratch`、常驻置顶、不可重命名 / 删除，激活期自愈（被外部删掉后自动重建）。
- 归档：把临时记事内容**剪切**进 `archives/<起日_今日>.md`（源文档随后清空），归档页只读打开；同名归档追加 `_2` / `_3`，不覆盖旧记录。
- 笔记管理：新建 / 打开 / 重命名 / 删除 / 搜索；笔记文件为 `~/.wasmnest/lanbitou/notes/<id>.md`，列表由 `index.json` 元数据与目录扫描合并，外部新增 / 删除自动同步，索引损坏时按目录重建。
- 保存模式：实时（默认 500ms 防抖）/ 失焦 / 手动（Ctrl+S）；状态栏显示保存状态。
- 工作上下文：恢复最后打开的笔记、光标位置与滚动位置。
- 时间分隔符：支持顶部 / 底部 / 光标处，格式可配置；距上次编辑超过阈值自动插入，手动删除后该笔记不再自动插入。
- 编辑 / 预览 / 分屏三种视图模式。
- 系统剪贴板：复制选中内容 / 从剪贴板粘贴（经宿主 clipboard 能力，权限 `clipboard:read` / `clipboard:write`）。
- 外观与编辑器设置：主题（跟随系统 / 浅色 / 深色）、字号、字体、界面语言（zh-CN / en）。
- 侧边栏笔记列表、字数 / 字符统计。
- 桌面端支持多任务卡片只读预览（`mountPreview`）。

### 修复

- 自动保存并发：落盘串行化（防抖 / Ctrl+S / 切换笔记并发时旧内容后落覆盖新内容），保存完成只在目标未被推进时清空待保存状态（否则状态栏谎报「已保存」）。
- 卸载前先落盘：关闭应用时先 flush 未保存正文与工作上下文，再卸载（原先 fire-and-forget 不保证完成）。
- 路径包含判定按路径组件比较（不再用字符串前缀，`/x/notes-evil/a.md` 不会被误判为在 `notes/` 内）。
- 笔记目录读取失败不再伪装成空列表（权限 / IO 错误上抛，避免「笔记全没了」的错觉）；索引损坏整份回退为空索引后按目录重建。
- 多任务预览不再改写主应用语言（预览挂载 / 卸载不得动用户的语言选择）。
- 工作上下文写入失败留痕（写失败不阻断编辑，但不再静默吞掉）。

### 变更

- 去掉 `storage` 权限：数据全部落在 `~/.wasmnest/lanbitou` 的文件与索引，不再用插件私有库。
