# Changelog

本文件记录 **BedCode**（`com.wasmnest.bedcode`）的版本变更。桌面与移动端共用同一版本号与发布 tag。

- 版本真源：`apps/bedcode/{desktop,mobile}/plugin.json` 的 `version`，双端必须一致。
- 发布 tag：`bedcode-v<X.Y.Z>`；发布流程见 [`docs/CI.md`](../../docs/CI.md) §2。
- 结构参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号遵循 [Semantic Versioning](https://semver.org/lang/zh-CN/)。
- 发布时把 `[Unreleased]` 收为 `## [<version>] - <YYYY-MM-DD>`，与版本号、tag 同一批提交。

## [Unreleased]

### 新增

- 项目容器与工作台：项目以「本地目录 + 执行环境」为身份，新增项目列表 / 工作台（运行列表 + 终端主面 + 检查器）与 `project.*` / `run.*` 命令面；`sessions` 账本迁移为 `runs`，旧「终端会话」入口保留并存。
- 项目工作台检查器：文件树（懒加载、只读查看）与 Git 提交图（分支 DAG、提交历史、引用徽标；打开页签才读取）。
- 项目工作台拼屏：多条存活运行的终端同屏（最多 4 格自适应网格，点格子换焦点；超过 4 条由左栏点选换入，模式按项目记忆）。
- 项目工作台终端 header：补齐独立终端窗口的功能（停止 / 任务队列 / 设置面板 / 清屏 / 刷新格式 / 状态与运行时长），并与独立窗口共用同一实现（`useTerminalChrome` + `TerminalSettingsPanel`）。
- 运行内 agent 控制：终端 header 新增模型与思考等级下拉，切换在当前运行内生效（不重启、保留对话上下文）。四家按能力适配——pi / opencode 走桥接原生接口，claude / codex 走 PTY 内联斜杠命令（codex 需 0.164+，低于该版本显性提示更新）；不可用态给结构化原因，不静默禁用。新增 `run.agent.options` / `run.agent.set` 命令面。
- Agent 编排（v1）：新增 `/orchestrations` 顶层模块（列表 + 详情），支持手动 / AI 规划两种计划来源；计划批准后由确定性调度器经现有 run / 桥接派发，写集租约 + 内容指纹证据 + 可选验收命令 / reviewer verdict 判定成功；支持暂停 / 恢复 / 重试 / 跳过 / 取消、工作流图、执行流水线、参与者、时间线与证据面板；v1 仅编排 pi / opencode。
- 移动端项目页：底栏「会话」改为「项目」，项目列表 → 运行 → Agent 启动；新增项目 / 运行 / Agent 读面与 `start-run` 写面。
- Agent 管理域（原 agent-hub 并入）：Node.js 环境引导 / 移除、CLI 探测 / 安装 / 更新 / 卸载、供应商预设导入与下发、用量统计、Skill 扫描 / 导入 / 编辑 / 分发；安装卡片可直达会话配置。
- 会话日志恢复：日志详情新增「恢复会话」，按 adapter + CLI 会话 ID 生成各家 resume 命令（pi / opencode `--session`、codex `resume`、claude `--resume`），弹窗确认工作目录 / 环境 / 命令后启动终端。
- 应用内检查更新：双端接入宿主 `appUpdate`，`plugin.json` 声明 GitHub Release 更新源。
- 移动端终端内置 Sarasa Mono SC 等宽字体。
- 项目文件查看器接入 shiki 源码高亮：懒加载双主题、超长文件与加载异常降级为纯文本；依赖精确钉 4.5.0（老 WebKitGTK 不支持 4.6 的 wasm 装载形态）。
- 任务日志详情：按 CLI 会话 id 复用会话转写（`session.task.log-session`），未索引 / 读取失败 / 无内容三态显性区分并支持恢复会话；会话转录内容面在任务详情与 Agent 日志详情间复用。pi 桥接模板升至 v11 上报会话身份。
- 移动端项目详情只列活跃运行，Agent 选择器改用各家官方品牌图标（与桌面同源，跨端比对锁）。

### 变更

- 项目运行列表与 agent CLI 同生命周期：只展示存活运行，用户在 CLI 里 exit / 进程结束即从列表消失；结束的运行不再需要手动整理（取消归档面），记录仍保留在会话域。
- 项目工作台拼屏：运行相关控制（停止 / 模型 / 思考等级 / 任务队列 / 独立开窗）下放到每格终端顶栏；全局 header 只保留拼屏开关、设置与焦点终端动作。
- 终端输入条结构重构，显示设置拆为独立 store（issue #19）。
- 链路加密策略改为按应用设置：应用设置页决定不要求（off）/ 尽量加密（preferred）/ 强制加密（required），宿主只执行与只读审计，未设置 = 明文（端点注册不再声明 encryption）。WS 升级期协商（客户端提案 + 101 策略/密钥回执）已接线，`required` 同时覆盖 HTTP 与 WS 帧级加密；旧宿主（能力 `wsSession=false`）仍禁用 `required` 并显性说明。
- Agent 展示顺序改为 pi → opencode → codex → claude，四家 Agent 使用各自 TUI 强调色。
- 移动端设置步进器随视口流式缩放并去掉按钮底板。
- 会话日志详情「任务记录」改为倒序展示，最新回复在最上面（回看场景先看结果）。
- 移动端终端渲染器改为 WebGL 优先（加载失败 / context loss 自动回退 DOM），保留显式开关做 A/B。
- Agent 池收全部已安装 CLI（含无桥接的 claude / codex），可编排性改由视图 `orchestratable` 显性表达。

### 修复

- 终端重放起点对齐与尾部窗口裁剪（issue #1 F3 / F6）。
- 运行列表状态统一出字符串标签：终态运行（宿主重启后被标记 interrupted）不再被工作台误判成存活而反复拉取已回收的 PTY；输出拉取连续失败达上限即停止轮询，不再把未处理 rejection 灌成全局「未知错误」提示风暴。
- 项目文件 / 提交图：加载中点击刷新不再被静默忽略（force 刷新可覆盖在途请求）。
- 任务日志时间筛选：修复访问过 Agent 管理后，开始/结束时间日期框的日历图标与文字重叠（hub 日期框样式全局注入泄漏到其他页面）。
- Agent 管理卡片「启动会话」的启动命令改为恒取目标 agent 的 `binary`，不再被会话中心上次保存的命令覆盖（点 pi 卡片却启动 claude 的错对象问题）。
- 项目工作台选中终态运行（宿主重启后遗留的 interrupted 运行）不再挂空终端：主面显性提示「运行已结束」；终端组件对无 PTY 的会话（stopped / error / idle）不再发 resize / 输入命令，消除 `session.action.resize` 的「缺少 PTY 句柄」错误日志。
- 设备配对 QR 的中继降级文案补 `{message}` 插值，不再把原因只放在 title 而留下未替换占位符。
- 会话转写角色文案改静态字面量映射，纳入 `plugin-contract` C6 完整性门禁。
- 穿透配置中心审核修复：未登记业务的 WAN 生效值按后端默认「允许」呈现、预览卡把存储损坏显示为读取失败、导入指纹复算等待落定、移除失败改用专门文案。
- 恢复被误清空的变更记录并补齐本轮条目。

### 安全

- i18n 消息改为构建期预编译，移除运行时编译与 CSP `unsafe-eval` 前提（安全审查 #50）。

## [0.0.1] - 2026-10-27

### 新增

- 配对与信任：配对码 / QR token 生命周期、首连确认、可信设备与撤销、链路加密。
- 设备中心与连接历史：已配对设备管理、历史连接记录。
- 会话中心：会话配置与生命周期编排，创建会话时自动注入项目 hooks 同步任务状态。
- 任务队列：终端工具栏任务队列与任务历史；移动端提供预设任务入口与定时任务 / 任务记录的只读投影。
- 移动端终端流：订阅回放 + 实时输出，断线自动重连并补齐环窗口，渲染背压 ack，输出风暴期自动驻留。
- 移动端输入：可打印文本与特殊键（Ctrl+C / 方向键 / 功能键）直达桌面 PTY；支持扫码 / 配对码与生物识别解锁。
- 认证角色外迁：认证中心由 `servers/auth-center` 承担（K4 单中心），设备中心 / consent / 连接记录经互调消费；BedCode 不再注册为认证中心。
- 设置：配对码 TTL、QR 有效期、hooks 等业务分组；平台设置留在宿主系统页。
- 桌面 + 移动双端发布；桌面端支持多任务卡片只读预览（`mountPreview`）。
