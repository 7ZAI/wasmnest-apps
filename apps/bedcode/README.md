# BedCode（`com.wasmnest.terminal-session`）

终端会话中心：配对与信任、会话配置与生命周期编排、任务队列与 Agent 集成的单一权威。桌面为服务端（会话宿主），移动为远程终端控制端，双端协作。

支持端：桌面 + 移动

## 功能特性

### 桌面（服务端）

- **配对与信任**：配对码 / QR 码生成与校验、设备信任管理、链接加密
- **设备中心 / 连接历史**：已配对设备管理、历史连接记录
- **会话中心**：会话配置与生命周期编排，创建会话时自动安装项目 hooks 同步任务状态
- **任务队列**：Agent 任务队列弹窗（终端工具栏入口）与任务历史
- **设置**：配对码 TTL、QR 有效期、hooks 等配置（平台分组在宿主系统页）

### 移动（远程终端控制端）

- **终端流**：订阅桌面端会话的终端输出并发送输入，断线自动重连并补齐环窗口
- **输入**：可打印文本与特殊键（Ctrl+C / 方向键 / 功能键）直达桌面 PTY
- **流控**：渲染背压 ack，输出风暴期自动驻留防卡顿
- **自动任务面板**：预设任务 / 定时任务 / 任务记录（后两者为桌面任务域的只读视图）
- **配对**：扫描二维码 / 输入配对码，生物识别保护

## 使用方式

桌面：侧边栏「设备配对 / 连接历史 / 终端会话 / Agent任务」四目录；会话创建时自动安装项目 hooks 同步任务状态；终端工具栏按钮打开任务队列弹窗。

移动：两端连接后进入会话终端页即自动订阅；离开页面自动断开（不在后台常拉）。自动任务在会话工具栏「自动任务」入口打开，选目标会话后创建任务入队，开启自动执行即按队列顺序调度。
