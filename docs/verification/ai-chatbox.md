## 3. 验证步骤

### F-01 挂载与聊天区（核心）

- [ ] **S-01-01** 从宿主侧边栏打开「AI 对话」。期望：聊天区可见，左侧对话列表、消息输入框、设置齿轮均就位。
- [ ] **S-01-02** 在**未配置供应商**的干净环境进入。期望：显示空态图标、「请先配置 AI 模型」与「配置模型」按钮；输入框不渲染；点击按钮直达模板选择页。
- [ ] **S-01-03** 在已配置供应商但无消息时进入。期望：显示「开始新对话」类空态；输入框可输入。
- [ ] **S-01-04** 点击侧栏折叠按钮。期望：侧栏折叠为窄条，仅保留展开与新建；再次点击复原。折叠态在重进应用后保持（持久化）。
- [ ] **S-01-05** 点击设置齿轮。期望：进入配置页；点击返回回到聊天区。
- [ ] **S-01-06** 切换宿主语言（zh-CN / en）。期望：聊天区、设置页、空态文案随语言切换。

### F-02 供应商配置（核心，【需 Key】）

- [ ] **S-02-01** 设置页查看「已配置的供应商」摘要。期望：默认展开，行内显示供应商名 / 模型 / Key 掩码；折叠后列表不可见但数据仍在；再次展开恢复。
- [ ] **S-02-02** 点击「添加供应商」。期望：进入模板选择页，至少显示 DeepSeek / 通义千问 / OpenAI / Anthropic 与「自定义」。
- [ ] **S-02-03** 选择任一预设。期望：表单回填名称、Base URL、模型；可修改后保存。
- [ ] **S-02-04** 表单校验：清空名称 / Base URL / API Key。期望：必填项阻止保存并给出提示；三者齐全后才可保存。
- [ ] **S-02-05** 点击「拉取模型」（需网络）。期望：成功时用返回列表替换模型列表；空结果或失败时就地提示且保留原列表；无 Key / 非法 Base URL 时不发请求。
- [ ] **S-02-06** 点击「测试连接」。期望：成功显示「连接正常」类文案；失败显示友好错误（不泄漏 Key）；API Key 可切换显示/隐藏。
- [ ] **S-02-07** 保存供应商。期望：返回设置页并在摘要中可见；进入聊天区后模型选择器包含该供应商模型。
- [ ] **S-02-08** 编辑已保存供应商并保存。期望：摘要与模型选择器同步更新；已选中的模型失效时有明确回落。
- [ ] **S-02-09** 删除供应商。期望：桌面弹出确认弹窗；取消不删除；确认后从摘要与模型选择器移除。移动端使用宿主确认弹窗（见 F-10）。
- [ ] **S-02-10** 关闭未保存表单。期望：返回后不产生新供应商；无脏数据残留。

### F-03 会话管理（核心）

- [ ] **S-03-01** 点击「新建对话」并发送首条消息。期望：对话列表新增一项；标题取首条消息前 30 字并带省略号。
- [ ] **S-03-02** 新建第二条对话并发送不同内容，再切回第一条。期望：消息、模型、用量随会话恢复；不串消息。
- [ ] **S-03-03** 双击标题或点击重命名入口。期望：进入编辑态；Enter 提交、Esc 取消；空标题不保存。
- [ ] **S-03-04** 删除当前对话。期望：桌面无二次确认（按现有实现）；删除后消息区清空、列表移除；移动端有确认（见 F-10）。
- [ ] **S-03-05** 在发送 / 流式期间尝试切换或新建。期望：操作被阻止且不破坏当前流；流结束后恢复可用。
- [ ] **S-03-06** 删除全部对话。期望：显示「暂无对话」空态与提示，不显示残留消息。
- [ ] **S-03-07** 重启应用 / 宿主后重进。期望：会话列表与消息恢复（持久化），排序合理。

### F-04 发送与流式对话（核心，【需 Key】）

- [ ] **S-04-01** 输入文本按 Enter。期望：消息发送，用户消息立即上屏；输入框清空。
- [ ] **S-04-02** 输入多行文本按 Shift+Enter。期望：换行不发送；再按 Enter 发送。
- [ ] **S-04-03** 观察流式输出。期望：assistant 内容逐段追加；发送按钮变停止；滚动跟随；首个 chunk 前不显示停止按钮。
- [ ] **S-04-04** 流式中点击停止。期望：保留已接收内容；停止后写入会话；按钮恢复发送。
- [ ] **S-04-05** 完成一次对话。期望：显示模型名与 token 用量（若供应商返回）；消息可继续追问。
- [ ] **S-04-06** 对最后一条 assistant 点击重新生成。期望：重新发起请求并替换该条；历史消息保留。
- [ ] **S-04-07** 切换供应商 / 模型后发送。期望：请求使用当前选择；回复中的模型标识与选择一致。
- [ ] **S-04-08** 空输入 / 纯空白。期望：发送按钮置灰或不可发送，不产生空消息。

### F-05 消息渲染与操作（核心）

- [ ] **S-05-01** 发送包含 Markdown 标题、列表、表格、链接、粗体的消息。期望：渲染正确，无原始标记泄漏。
- [ ] **S-05-02** 发送包含代码块的消息。期望：代码块有语言标签与复制按钮；复制内容正确；高亮生效。
- [ ] **S-05-03** 悬停用户 / assistant 消息。期望：出现复制 / 删除操作；复制成功有反馈；删除后对应消息消失。
- [ ] **S-05-04** 发送含 HTML / script 的内容。期望：脚本不执行，危险标签被清理（DOMPurify）。
- [ ] **S-05-05** 长对话滚动到顶部 / 底部。期望：消息完整、不重叠；流式时自动跟随，手动上滚后不被强制拉回（按现有实现记录）。
- [ ] **S-05-06** 移动端对照：用户消息为纯文本、assistant 无品牌头像、操作常显、代码高亮由 Shiki 异步加载。期望：与桌面差异符合实现，不把差异记为缺陷。

### F-06 思考与限流（核心，部分需构造）

- [ ] **S-06-01** 设置思考模式为 default 后发送。期望：请求不附加 thinking 参数；回复正常。
- [ ] **S-06-02** 切换为 enabled，分别选择低 / 高 / 最大推理强度。期望：仅 enabled 时显示强度；请求带上对应参数（用支持思考的模型验证，抽样检查回复或日志）。
- [ ] **S-06-03** 切换为 disabled。期望：强制关闭思考；思考过程不显示。
- [ ] **S-06-04** 开启 / 关闭「显示思考过程」。期望：支持思考的模型在开启时展示 thinking，关闭时隐藏；不影响回复正文。
- [ ] **S-06-05** 将限流重试设为 0，制造 429 / 503 / 529 或 rate limit 文本。期望：不自动重试，直接显示限流错误。
- [ ] **S-06-06** 将重试设为 >0 并制造限流（在收到首个内容前）。期望：出现倒计时横幅，指数退避；可终止；重试耗尽或终止有专门文案。
- [ ] **S-06-07** 在已收到部分内容后制造限流。期望：不自动重试（按现有实现），已接收内容保留并提示。
- [ ] **S-06-08** 使用错误 Key / 无权限 Key。期望：分类显示授权失效 / 鉴权错误；不展示技术原文（桌面未知错误统一兜底）。
- [ ] **S-06-09** 断网发送。期望：显示网络类错误；界面不崩溃；恢复网络后可继续。

### F-07 应用设置（核心）

- [ ] **S-07-01** 调整代码字体大小。期望：范围 11–18；到边界时对应按钮禁用；代码块即时变化。
- [ ] **S-07-02** 调整行距。期望：范围 0.5–2.0；桌面支持方向键 / Home / End；代码块即时变化。
- [ ] **S-07-03** 切换代码主题（6 档，含 auto）。期望：代码高亮主题变化；auto 跟随宿主深浅色。
- [ ] **S-07-04** 调整思考模式与推理强度。期望：与 F-06 行为一致；设置即时保存。
- [ ] **S-07-05** 调整限流自动重试次数 / 初始等待 / 最大等待。期望：次数 0–10（0 显示「关闭」）；初始 0.5–10s；最大 5–60s；越界被限制。
- [ ] **S-07-06** 退出设置页再进入 / 重启应用。期望：所有设置保持。
- [ ] **S-07-07** 移动端重复关键项。期望：取值域一致；滑块仅指针拖动；代码主题为下拉；设置持久化。

### F-08 持久化与预览（核心）

- [ ] **S-08-01** 完成 2 个以上会话后重启桌面应用 / 宿主。期望：会话与消息完整恢复，顺序稳定。
- [ ] **S-08-02** 核对 JSONL 对话日志已落盘（按插件存储布局或应用数据目录）。期望：每次对话有记录，字段可追溯；删除会话后对应策略符合实现（记录实际行为，不假设）。
- [ ] **S-08-03** 在宿主多任务卡片查看 AI Chatbox 预览。期望：按状态显示最近对话 / 3 条消息摘要，或 loading / no-provider / no-conversation / unavailable / ready 五态之一。
- [ ] **S-08-04** 预览期间观察网络与存储。期望：预览只读，不发起模型请求、不写存储；退出后主应用会话不变。

### F-09 移动端运行面（核心，真机）

- [ ] **S-09-01** 从移动宿主应用列表打开 AI Chatbox。期望：全屏聊天页；头部含对话列表、标题、新对话（已配置供应商时）与设置。
- [ ] **S-09-02** 点击左侧对话列表按钮。期望：抽屉从左侧展开（约 82vw，最大 320px）；点击遮罩关闭；选择对话后自动关闭。
- [ ] **S-09-03** 抽屉内新建 / 切换 / 重命名 / 删除对话。期望：功能与桌面一致；操作常显，不依赖悬停。
- [ ] **S-09-04** 打开设置页与供应商模板 / 表单。期望：字段与桌面一致；保存 / 拉取模型 / 测试连接可用；删除使用宿主确认弹窗。
- [ ] **S-09-05** 查看输入区模型 pill。期望：位于左下，向上弹出模型列表；无供应商时隐藏。
- [ ] **S-09-06** 发送消息并观察流式与代码高亮。期望：流式正常；Shiki 高亮异步加载；代码块可复制。
- [ ] **S-09-07** 验证无侧栏差异。期望：移动端没有桌面侧栏；折叠 / 展开入口不存在，不记为缺陷。

### F-10 移动端确认与返回（核心，真机）

- [ ] **S-10-01** 删除对话。期望：宿主确认弹窗；取消不删除；确认后删除当前对话并清空消息区。
- [ ] **S-10-02** 在设置页内部视图（模板 / 表单）按系统返回键。期望：逐级返回设置页 → 聊天页，不直接退出应用。
- [ ] **S-10-03** 在聊天页按系统返回键。期望：交还宿主（回应用列表 / 上一页），不卡死。

- [ ] **S-10-05** 旋转 / 小屏下检查设置页与消息区。期望：可滚动、关键操作不被遮挡；键盘弹出时输入框可见。
