# BedCode 端到端功能验证模板

> **模板版本**：v2（2026-11-06；agent-hub 并入后同步）
> **适用对象**：`com.wasmnest.bedcode`（`apps/bedcode/desktop` + `apps/bedcode/mobile`）
> **报告用法**：复制到 `docs/verification/reports/<YYYY-MM-DD>-bedcode-v<版本>.md`，
> 按 §3 执行；标记口径见 [README.md](README.md) §3.3。
> **双端前提**：桌面是会话宿主（PTY 所在端），移动是远程控制端。跨端步骤必须两端同时在位；
> 只验单端时把另一端步骤标 `⏭` 并写明。
> **配套分册**：Agent 管理域（原 agent-hub 并入，见 [ADR 0002](../adr/0002-agent-hub-merge-into-bedcode.md)）
> 的功能清单与人工步骤见 [agent-hub.md](agent-hub.md)；发版验证时其 §2 / §3 需一并追加进本报告 §6，
> 六分区交互无 E2E 覆盖，不得只凭 `--app bedcode` 的导航用例判该域通过。

## 2. 验证准备

- [ ] **P-01** 桌面：`apps/bedcode/desktop` 执行 `pnpm install` + `pnpm run test:run` + `pnpm run build`；期望全绿且构建成功。
- [ ] **P-02** 桌面：跑 `node scripts/e2e.mjs --app bedcode`；期望 12 例通过（含 Agent 管理域 `hub-view` 导航与日期框样式回归）。
- [ ] **P-03** 双端：按 `docs/E2E.md` §10 准备真机、debug APK、USB 调试；跑 `node scripts/e2e-dual.mjs --app bedcode`，记录结果。若不做双端，F-13 标 `⏭`。
- [ ] **P-04** 确认认证中心已注册（桌面主屏「服务」区 → 认证中心 → 就位状态「已就位」）；否则先修认证中心，不把 BedCode 配对失败记成 BedCode 缺陷。
- [ ] **P-05** 准备测试用会话配置与 Agent CLI（claude / codex / opencode / pi 任一），确认 PTY 配额（`ptyQuota: 8`）未被占满。
- [ ] **P-06** 准备测试用移动设备，完成 USB 调试与同网段连接；清空或备份测试配对记录，避免污染真实用户数据。
- [ ] **P-07** 记录桌面 IPv4 与 WS 端口；多网卡时确认选中的地址是手机可达的那一个。
- [ ] **P-08** 按 [agent-hub.md](agent-hub.md) §2 完成 Agent 管理域前置（CLI 安装态、目录授权、npm / GitHub 网络、测试用 CLI 配置与 Skills 目录、Provider 预设迁移桥文件）；F-15 的人工步骤并入本报告 §6。
- [ ] **P-09** 内网穿透前置（F-16）：自建 relay 可达（`wasmnest-relay print-addrs --json` 有输出）或标记 F-16 为 `⏭`；手机准备「同网段 Wi-Fi」与「蜂窝」两种网络；记录 relay multiaddr 与该地址的 PeerId 指纹（用于桌面卡片导入）。

## 3. 验证步骤

> 自动化锚点以源码为准；桌面主要锚点见 `e2e/pages/` 与 `docs/E2E.md`，移动端统一 `mobile-` 前缀。
> 连接历史是设备列表「历史」按钮的深链页，**不在侧栏**（侧栏七项见 §0，含并入的 Agent 管理）。

### F-01 挂载与导航（核心）

- [ ] **S-01-01** 从宿主侧边栏打开 BedCode。期望：应用挂载，进入默认页（终端会话），侧栏显示七个目录项（设备配对 / 项目 / 终端会话 / Agent 管理 / Agent 编排 / Agent 任务 / 设置）。
- [ ] **S-01-02** 依次点击七个侧栏目录。期望：目标视图渲染、选中态跟随、前一视图完成退场后不可见（对应 `bedcode.spec.ts` 的导航用例）；Agent 管理的目标视图为 `hub-view`。
- [ ] **S-01-03** 在设备配对页确认没有「连接历史」侧栏项。期望：连接历史只能从设备行「历史」或深链进入；记录与 README 的口径差异（见 §4）。
- [ ] **S-01-04** 从设备行「历史」进入连接历史，再返回。期望：深链页渲染、返回后回到设备中心。
- [ ] **S-01-05** 打开一个运行中的终端窗口（独立路由 `/terminal-window/:id`）。期望：不套侧栏外壳，窗口独立渲染。
- [ ] **S-01-06** 访问未匹配路由。期望：显示显性 NotFound，不白屏。

### F-02 设备配对：码与 QR（核心）

- [ ] **S-02-01** 进入设备配对页，查看网络信息条。期望：显示 IPv4 下拉与 WS 端口；无 IPv4 时显示「未找到可用的 IPv4 地址」。
- [ ] **S-02-02** 多网卡时切换 IPv4。期望：选择写入插件存储；活跃 QR 按新 host 重组且 token 不重签；刷新时重读网络、设备与中心状态。
- [ ] **S-02-03** 点击生成配对码。期望：显示 6 位码与剩余秒徽标，倒计时递减；TTL 与设置页配对有效期一致。
- [ ] **S-02-04** 点击取消配对码。期望：码消失；无残留倒计时。
- [ ] **S-02-05** 生成后等待倒计时归零。期望：自动清除并回到空态（「点击下方按钮生成配对码」）。
- [ ] **S-02-06** 生成 QR。期望：canvas 白底渲染；显示单次使用提示；随选中 host 生成；可刷新。
- [ ] **S-02-07** 取消 QR。期望：QR 清除，回到可生成状态。
- [ ] **S-02-08** 离开页面再返回（已有 QR）。期望：恢复既有 QR，不重签 token；KeepAlive 切回后重绘正常。
- [ ] **S-02-09** 制造命令失败（关闭认证中心 / 断通道）。期望：失败 toast 或横幅，不静默显示已生成。
- [ ] **S-02-10** QR 在场时点击「复制连接串」（`pairing-qr-copy-link`）。期望：剪贴板得到 `wasmnest://pair/…`，解码后与 QR 载荷逐字段一致（同含一次性 token）；剪贴板不可用时显性报错，不提示已复制。

### F-03 设备列表与连接历史（核心）

- [ ] **S-03-01** 查看设备列表：在线 / 离线两个分区与计数。期望：空分区显示「暂无数据」；设备行显示名称、配对于、上次连接、连接次数。
- [ ] **S-03-02** 连接 / 断开一台测试设备（双端或宿主事件模拟）。期望：在线状态随之迁移，计数更新。
- [ ] **S-03-03** 对一台测试设备点击「移除」。期望：确认弹窗；取消不删除；确认后撤销信任并 toast，列表更新。
- [ ] **S-03-04** 点击设备行「历史」进入连接历史。期望：设备下拉默认第一台；记录按日分组，含认证方式 / 地址 / 时段 / 成功失败。
- [ ] **S-03-05** 查看历史统计与空态。期望：显示 total / ok / fail；无记录显示「暂无连接历史」；加载失败有 toast。
- [ ] **S-03-06** 点击「清空历史」并确认。期望：仅清空记录；设备与信任不变；取消不删除。
- [ ] **S-03-07** 无设备时进入历史。期望：不取数、显示空态，不报错。

### F-04 认证中心状态与密钥（核心）

- [ ] **S-04-01** 查看设备中心的认证中心横幅。期望：`registered` 时不显示阻断；`not_ready` 显示红色横幅与入站被拒说明；`unknown` 显示灰色「状态未知」；横幅跨 Tab 保持。
- [ ] **S-04-02** 点击入场密钥轮换。期望：确认弹窗；确认后显示新代次 `kid` 成功 toast；设备列表不刷新。
- [ ] **S-04-03** 轮换失败（断通道）。期望：失败 toast，代次保持不变；不静默成功。
- [ ] **S-04-04** 对照 [auth-center.md](auth-center.md) 的密钥代次卡确认代次一致。期望：BedCode toast 中的 `kid` 与认证中心密钥卡一致。
- [ ] **S-04-05** 检查 trust-list / consent 是否有 BedCode 页面入口。期望：无入口（这些能力由认证中心与 File Transfer 消费）；记录为设计现状，不记缺陷。

### F-05 会话配置与生命周期（核心）

- [ ] **S-05-01** 进入终端会话页，切换「终端配置 / 运行中的会话(n)」。期望：两个 Tab 内容正确，运行中数量与列表一致。
- [ ] **S-05-02** 点击刷新。期望：刷新动作可触发，界面保持在位，不白屏。
- [ ] **S-05-03** 点击新建（或 Ctrl/⌘+N）。期望：打开配置表单弹窗；Esc / 取消可关闭且不落配置。
- [ ] **S-05-04** 填写表单：名称、环境（按平台过滤）、WSL 发行版（仅 wsl2）、工作目录（系统选择器）、命令预设（claude / codex / pi / opencode / 自定义）。期望：必填项内联校验；WSL 枚举失败有显性提示；保存后成为下次新建默认值。
- [ ] **S-05-05** 对配置卡点击启动。期望：先显示窗口网格预测；创建成功后 toast；失败 toast 并撤销遮罩，不留下假窗口。
- [ ] **S-05-06** 对运行中会话点击「查看终端」。期望：running / waitingInput 可打开；其他状态给 info toast；新窗显示 opening 遮罩。
- [ ] **S-05-07** 点击重启。期望：会话重启并在列表中更新状态；失败有提示。
- [ ] **S-05-08** 点击停止并确认。期望：会话关闭、对应终端窗口关闭；stopped 会话从运行列表移除。
- [ ] **S-05-09** 点击删除（运行中先停再删）。期望：配置删除；相关会话按实现处理；列表刷新。
- [ ] **S-05-10** 触发会话事件（创建 / 停止 / 移除）。期望：列表静默刷新，不重复弹窗、不闪烁。
- [ ] **S-05-11** 占满 PTY 配额（8）后继续启动。期望：拒绝并给出明确错误，不创建半成品会话。
- [ ] **S-05-12** 检查配置卡：环境徽标、`auto` 徽标仅展示；确认表单无 autoStart 控件、无重命名入口。期望：与实现一致，记录 §4 缺口。

### F-06 终端窗口（核心）

- [ ] **S-06-01** 打开终端窗口。期望：工具条显示会话名与状态；底栏显示运行时长。
- [ ] **S-06-02** 在终端输入命令并观察输出。期望：输入直达 PTY，输出实时渲染；可滚动查看历史。
- [ ] **S-06-03** 点击任务队列入口（仅任务域适配 Agent 的会话显示）。期望：打开任务队列弹窗；未适配会话不显示该入口。
- [ ] **S-06-04** 点击设置，调整主题 / 字号 / 字间距 / 背景图与不透明度。期望：即时生效；设置持久化或按实现作用域恢复。
- [ ] **S-06-05** 点击清屏 / 刷新格式。期望：清屏不破坏会话；刷新格式后输出按当前设置重绘。
- [ ] **S-06-06** 点击最小化 / 最大化 / 关闭。期望：窗口控制正常；关闭后会话状态与列表一致。
- [ ] **S-06-07** 从外部停止该会话。期望：终端窗口收到 `session:stopped` 后自动关闭，无残留窗口。

### F-07 Agent 任务（核心）

- [ ] **S-07-01** 进入 Agent任务页，确认四个 Tab：当前任务 / 任务日志 / 定时任务 / 统计。期望：默认 Tab 正确，切换无残留。
- [ ] **S-07-02** 在当前任务页创建任务：选择项目 + Agent（或勾选「保存为预设」）。期望：Enter 提交、Shift+Enter 换行；有活跃运行直接投递，无运行进入「等待运行」区；不可用目标给出提示。
- [ ] **S-07-03** 管理预设任务：创建时绑定项目 + Agent、加入队列 / 编辑 / 删除。期望：未绑定目标时禁用加入并提示；编辑即时生效；删除后列表更新。
- [ ] **S-07-04** 启动队列、切换自动模式与自动应答。期望：任务按队列顺序执行；状态与开关一致；失败有可见状态。
- [ ] **S-07-05** 查看当前执行任务卡与空态。期望：执行中显示任务与状态；无运行会话且无预设时显示空态引导。
- [ ] **S-07-06** 在任务日志页按状态 / Agent / 来源 / 起止时间筛选并重置。期望：结果随筛选变化；时间输入防抖；分页 10 条；空态明确。
- [ ] **S-07-07** 在定时任务页新建：名称、项目 + Agent、触发时间（UTC 预览）、多条 prompts 卡片。期望：校验通过后创建；到点无活跃运行会自动拉起一条运行；进行中 / 历史分组正确；历史默认折叠。

> 判据来自 `docs/design/nat-traversal/spec.md` §4（不变量）与 §7（P1 出口）。
> 「内网直连 / 外网中继」是**每对端**模式，不是全局开关；加密始终强制，页面上没有开关。
> 桌面锚点：`pairing-tunnel-status` / `pairing-tunnel-encryption` / `relay-settings-section` / `relay-current-peer-id`；

- [ ] **S-16-08** 未匹配拒绝：桌面设备页撤销该手机信任后，手机用已保存的 peer 记录直连（不带票据）。期望：显性 `not-matched` / 安全错误；不因失败自动改拨中继绕过。
- [ ] **S-16-09** 路由权限边界（对等面）：经隧道已匹配对端调 `task-status` / `session-mode`。期望：可达；调 `run-*` 四条桥接路由（run-start 等）一律 403。
- [ ] **S-16-10** 加密强制：抽查桌面设置与移动设置，链路加密无「关闭」项（桌面为只读徽标）。期望：无明文回退；制造链加密失败（旧客户端 / 缺链路身份）时显性提示 `encryption-required` / `encryption-unsupported`，连接失败而不是降级。
- [ ] **S-16-11** 断链语义：杀 relay 或断蜂窝。期望：移动显性 `relay-unreachable` / `peer-offline`，桌面离线显性 `peer-offline`；不出现「静默 30s 超时后才报错」。恢复网络后重连回到自动判定（不残留手动外网状态）。
