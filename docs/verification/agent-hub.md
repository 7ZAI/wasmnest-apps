> **报告用法**：复制到 `docs/verification/reports/<YYYY-MM-DD>-agent-hub-v<版本>.md`，

## 3. 验证步骤

> 自动化锚点（`data-testid`）以源码为准；本模板中的锚点仅用于对照 `e2e/pages/agentHub.ts`。
> 分支条件（已授权 / 已安装 / 有日志）按 P-04 / P-05 的真实状态执行，未出现的控件先确认前置。

### F-01 挂载与分区导航（核心）

- [ ] **S-01-01** 回到宿主主屏，确认应用网格存在「Agent Hub」应用卡；点击卡片。期望：应用挂载，默认落地「概览」分区，分区标签栏可见。
- [ ] **S-01-02** 确认分区标签共六个：概览 / 安装与更新 / Skills / 供应商 / 会话日志 / 使用统计；默认选中「概览」。
- [ ] **S-01-03** 依次点击六个分区。期望：每次目标面板可见、选中态跟随；前一面板完成退场后不可见。
- [ ] **S-01-04** 切到最后一个分区后返回主屏，再重新进入 Agent Hub。期望：应用重新挂载并回到默认概览，不残留上一分区的展开/弹窗状态。
- [ ] **S-01-05** 切换宿主语言（zh-CN ↔ en）后重进。期望：分区与主要文案随语言切换，无硬编码中文残留（专有名词除外）。

### F-02 概览：授权与环境检测（核心）

- [ ] **S-02-01** 在未授权状态进入概览。期望：顶部显示目录授权横幅与「授权」按钮；相关能力入口按未授权态禁用或提示。
- [ ] **S-02-02** 点击授权并选择 CLI 配置目录（`~/.claude` / `~/.codex` / `~/.pi` / opencode 等，按宿主选择器）。期望：授权完成后横幅消失，Skills / 供应商 / 日志等入口解除门控。若已授权：记录状态并直接执行 S-02-03。
- [ ] **S-02-03** 查看环境卡。期望：OS / 架构 / 版本 / Shell / Node / npm / pnpm / registry / Python 九项均有值或明确的「未检测到」；点击「重新检测」时期按钮禁用，完成后恢复。
- [ ] **S-02-04** 制造或模拟环境检测失败（例如 PATH 隔离）。期望：显示失败块与重试入口，且**不**显示 Node 安装入口；重试可恢复。
- [ ] **S-02-05** 触发 npm 源测速（需网络）。期望：显示最快源名称、耗时、推荐/官方标签；不可达源显示失败而不是假耗时。推荐 npmmirror 时出现「去安装页」入口，点击能切到安装与更新分区。
- [ ] **S-02-06** 在离线/测速失败状态重复 S-02-05。期望：失败文案诚实呈现，页面不崩、不显示伪造结果。

### F-03 概览：CLI 卡片（核心）

- [ ] **S-03-01** 查看四张 CLI 卡片。期望：claude / codex / opencode / pi 四张卡均渲染；名称正确；每张卡的状态徽章落在已知取值域（已装 / 已装未初始化 / 未安装 / 探测失败 / 检测失败 / 检测中 / 未检测）。
- [ ] **S-03-02** 对照 P-04 记录。期望：已安装 CLI 显示版本与安装方式；未安装显示未装；检测失败显示失败与重试入口。
- [ ] **S-03-03** 若存在双安装（同一 CLI 多个路径）：期望显示双安装警告与路径，卸载按钮按策略隐藏或给原因。
- [ ] **S-03-04** 对一张「已装且可自动卸载」的卡点击卸载。期望：第一击只进入确认态（按钮文案变化），**不执行卸载**，卡片与按钮仍在；等待超时（约 4 秒）后恢复初始态。
- [ ] **S-03-05** 再次点击卸载并确认（在测试环境专用 CLI 上）。期望：显示卸载中 / 忙碌态；完成后卡片状态更新为未装；失败时就地提示原因。
- [ ] **S-03-06** 对未知安装方式或 npm 缺失的卡片检查卸载入口。期望：不显示可执行按钮，并给出不可卸载原因。
- [ ] **S-03-07** 制造 `list-agents` 失败（或使用无 CLI 的隔离环境）。期望：显示降级横幅并回退内置四家目录，页面不空白。

### F-04 概览：Node 运行时引导（核心）

- [ ] **S-04-01** 在 Node 缺失环境查看概览。期望：出现「安装 Node.js」入口；点击打开引导弹窗，展示版本、平台、来源、大小、SHA、安装路径等字段。
- [ ] **S-04-02** 启动安装（测试环境）。期望：进度按阶段推进，显示已用时间；中途可取消；取消后回到可重试状态。
- [ ] **S-04-03** 制造下载/校验失败（断网或错误镜像）。期望：显示错误与重试入口，不把失败显示成完成。
- [ ] **S-04-04** 在已托管 Node 的环境查看入口。期望：显示升级 / 移除动作；移除弹窗有版本与警告，取消不产生副作用。
- [ ] **S-04-05** 若存在待清理的残留路径。期望：显示待清理提示；清理动作有明确结果反馈。

### F-05 安装与更新（核心）

- [ ] **S-05-01** 进入「安装与更新」。期望：显示当前源、测速结果表（推荐 / 当前标签）、各源可达性；不可达源显示失败。
- [ ] **S-05-02** 点击「换源」。期望：第一击进入确认态，不立即写入；确认后持久写入 npmrc，当前源标签更新。已是当前源或未授权时按钮禁用。
- [ ] **S-05-03** 添加自定义源：输入合法 URL 保存。期望：源出现在列表并可被选中；输入非法 URL 时就地报错且不保存。删除自定义源后列表恢复。
- [ ] **S-05-04** 若存在 npmrc 备份，点击「还原 npmrc」。期望：确认后恢复备份并给出结果；无备份时不显示该入口。
- [ ] **S-05-05** 对一张 CLI 行点击「检查更新」。期望：显示检查中状态；有在途 run 时禁用；结果落在安装 / 更新 / 已是最新 / 检测中 / 检测失败范围内。
- [ ] **S-05-06** 在缺 Node 的非 standalone CLI 行查看提示。期望：显示缺失提示与 `describe-install` 命令，可复制（约 2 秒「已复制」反馈）；安装仍可点击并由 guest 拒绝后进入引导链。
- [ ] **S-05-07** 执行一次安装或更新（测试环境）。期望：出现输出控制台，显示状态、命令、流式输出并自动贴底；可取消；失败显示文案。
- [ ] **S-05-08** 验证命令被拒分支。期望：行上方出现命令错误提示，不静默失败。

### F-06 Skills（核心）

- [ ] **S-06-01** 进入 Skills 并点击扫描。期望：显示库根与技能数量、各支持目标的「已同步 / N 落后 / 未分发」状态；扫描中按钮禁用。
- [ ] **S-06-02** 在未授权状态查看 GitHub 安装与本地导入。期望：入口禁用并显示授权横幅；授权后入口可用。
- [ ] **S-06-03** 点击 GitHub 安装。期望：首次点击展开表单（URL 输入 + 安装），再次点击收起；不可达仓库显示错误与原始错误文本；成功显示安装数与跳过文件数。
- [ ] **S-06-04** 用同名技能再次安装。期望：出现覆盖确认；取消不写入，确认后覆盖并刷新列表。
- [ ] **S-06-05** 本地导入：选择目录。期望：取消时无副作用；同名时出现覆盖确认；结果行显示名称、文件数或失败原因。
- [ ] **S-06-06** 打开一个技能的编辑器，修改 Markdown 后点击保存。期望：先出现 diff 预览与 +/- 统计；无变更时不能确认保存；确认后保存成功并有短提示。
- [ ] **S-06-07** 制造磁盘冲突（保存前外部修改文件）。期望：显示磁盘 ↔ 草稿 diff，可选择「以我的版本覆盖」或「从磁盘重读」。
- [ ] **S-06-08** 对一个技能点击分发 / 重新分发。期望：显示分发中状态；完成后目标同步标签更新；未授权时禁用。
- [ ] **S-06-09** 检查空态与扫描失败态。期望：空库、扫描失败分别有明确文案，不显示伪造列表。

### F-07 供应商（核心）

- [ ] **S-07-07** 对预设行执行应用 / 编辑 / 删除。期望：删除为两击确认；0 模型预设显示警示；未授权时应用禁用。
- [ ] **S-07-08** 打开应用面板，选择多个目标并逐一检查 key 模式（stored / inline / source / none）。期望：codex 显示 env_key 与顶替模型 / 方言阻断提示；claude 桥接冲突需二次确认；无模型目标有预警。
- [ ] **S-07-09** 执行应用。期望：逐目标显示结果与重启提示；部分失败时表单保留并收敛到失败目标，不假报全部成功。
- [ ] **S-07-10** 清空测试预设后查看供应商空态。期望：空列表有明确提示，新建入口可达，不显示伪造预设。

### F-09 使用统计（核心）
