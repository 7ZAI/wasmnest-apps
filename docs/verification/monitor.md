# Monitor 端到端功能验证模板

> **模板版本**：v1（2026-10-26）
> **适用对象**：`com.wasmnest.monitor`（`servers/monitor/desktop` + `servers/monitor/mobile`）
> **报告用法**：复制到 `docs/verification/reports/<YYYY-MM-DD>-monitor-v<版本>.md`，
> 按 §3 执行；标记口径见 [README.md](README.md) §3.3。
> **定位**：Monitor 是随宿主分发的**系统服务**（`internal-business`），不是 L3 应用；
> 入口在主屏「服务」区，不在应用网格，也不提供卸载。它只读宿主注入的 metrics 快照。

- [ ] **P-01** 桌面：`servers/monitor/desktop` 执行 `pnpm install` + `pnpm run test:run` + `pnpm run build`；期望全绿且构建成功。
- [ ] **P-02** 跑 `node scripts/e2e.mjs --app monitor` 与 `node scripts/e2e.mjs --app monitor --spec e2e/specs/sys-apps.spec.ts`；期望 10 + 3 例通过并记录用例数。

- [ ] **P-04** 移动：准备 debug APK + 真机；若只验桌面，F-09 标 `⏭`。
- [ ] **P-05** 准备一个可制造「指标命令失败 / 宿主清单失败 / 零插件」的隔离环境（例如空插件目录或断开快照源），用于 F-06。

## 3. 验证步骤

### F-01 宿主入口与服务属性（核心）

- [ ] **S-01-01** 回到宿主主屏，查看「服务」区。期望：存在「运行监控」入口；应用网格中**不**出现 Monitor。
- [ ] **S-01-02** 点击「运行监控」。期望：打开监控页，页面加载，无需授权弹窗（随包来源跳过审批门）。
- [ ] **S-01-03** 打开应用管理 `/sys/apps`。期望：Monitor 出现在「系统服务」分组；不出现卸载按钮；有启用 / 自启开关。
- [ ] **S-01-04** 查看自启开关初始状态。期望：缺省为开（D4：默认自启，用户可关）。
- [ ] **S-01-05** 关闭自启开关再重进。期望：开关状态持久化；服务本身仍可手动打开（按宿主实现）。
- [ ] **S-01-06** 检查系统服务不提供卸载。期望：不出现卸载文案或按钮；与 L3 应用卡片区分。

### F-02 页头与实时刷新（核心）

- [ ] **S-02-01** 打开监控页。期望：显示标题「运行监控」与副标题「运行时指标 · 只读」。
- [ ] **S-02-02** 在没有自定义面板时查看页头。期望：只显示标题，不出现整页页签条，也不出现面板区 / 面板错误。
- [ ] **S-02-03** 查看「实时」徽章与更新时间。期望：徽章可见；更新时间随轮询变化（约 1 秒）；显示刷新间隔。
- [ ] **S-02-04** 点击刷新。期望：按钮显示「刷新中…」并禁用；完成后恢复；无错误 banner；更新时间更新。
- [ ] **S-02-05** 制造一次刷新失败（已有旧数据）。期望：保留旧数据、隐藏「实时」、显示「数据已过期」；继续轮询可自动恢复。
- [ ] **S-02-06** 首次进入时观察加载态。期望：显示加载骨架，不显示空表冒充数据。

### F-03 KPI（核心）

- [ ] **S-03-01** 查看插件数 KPI。期望：显示「运行中 / 总数」；宿主清单不可用时运行数显示 `—`，并显示「另有 N 个未就绪」。
- [ ] **S-03-02** 查看调用总数、在飞调用、Trap 总数、内存峰值合计。期望：五项均有值或诚实的不可用态；在飞提示含本应用自身指标调用。
- [ ] **S-03-03** 制造 Trap > 0（测试插件或已有异常插件）。期望：Trap KPI 变红；数值与详情中的 Trap 原因一致。
- [ ] **S-03-04** 观察 KPI 随时间变化。期望：调用数 / 在飞 / 内存随快照更新；不出现负数或跳变到 0 再跳回。
- [ ] **S-03-05** 在指标不可用状态查看 KPI。期望：显示不可用 / 原因，不铺一排 0 冒充正常。

### F-04 插件台账与过滤（核心）

- [ ] **S-04-01** 查看插件列表。期望：按「状态 → 角色 → 名称」排序；默认选中首行。
- [ ] **S-04-02** 检查每一行字段。期望：状态点 / 文案、名称与版本、角色徽标、plugin id、内存当前/上限与占比、调用数、Trap 数；本应用有「本应用」标签。
- [ ] **S-04-03** 状态徽章取值域。期望：运行中 / 降级 / 待授权 / 错误 / 未运行 / 状态未知之一，不出现未知文案。
- [ ] **S-04-04** 角色徽标。期望：基础服务 / 内部业务 / 应用按 manifest `kind` 映射；Monitor 自身显示「内部业务」。
- [ ] **S-04-05** 内存水位达到 ≥80% / ≥95%（可用测试插件制造）。期望：分别出现警告 / 危险样式；数值与占比一致。
- [ ] **S-04-06** 切换「全部 / 服务 / 应用」过滤。期望：服务含 L1 + L2；应用过滤不显示服务；各按钮显示计数；切换不改变取数全量。
- [ ] **S-04-07** 对比「应用」过滤的列表与计数。期望：列表包含非服务行（含 unknown），计数只数 `business-app`；记录该已知不一致，不记为通过。
- [ ] **S-04-08** 对无指标的插件行查看。期望：显示「指标不可用」，不显示一排零。
- [ ] **S-04-09** 点击任一行。期望：选中态切换，右侧 / 下方详情切换到该插件。

### F-05 详情与配额（核心）

- [ ] **S-05-01** 查看详情内存段。期望：当前 / 上限 / 占比、峰值、内存增长被拒次数、表增长被拒次数。
- [ ] **S-05-02** 查看调用段。期望：调用总数、在飞、平均 / 最大耗时、燃料、激活耗时；与 KPI 口径一致。
- [ ] **S-05-03** 查看耗时分布。期望：6 桶直方图渲染；桶标签与计数可读。
- [ ] **S-05-04** 查看 Trap 原因。期望：有 Trap 列出原因与计数；无 Trap 显示「未记录 Trap」。
- [ ] **S-05-05** 查看生命周期与最近事件。期望：激活 / 停用等计数与最近事件时间正确。
- [ ] **S-05-06** 查看授权决策与消息总线段。期望：放行 / 拒绝 / 待确认 / 记录丢弃、队列丢弃 / 格式拒绝均有值或 0。
- [ ] **S-05-07** 展开配额详情。期望：默认收起；点击展开后显示 6 项配额（燃料 / 内存 / 表元素 / 实例数 / 内存数 / 表数）；说明「以上是宿主配额上限，不是实时占用。」
- [ ] **S-05-08** 对宿主异常但无指标的插件查看。期望：显示 `指标不可用` 与原因，不显示伪造零值。
- [ ] **S-05-09** 若快照含宿主维度（如 `task`）。期望：显示宿主维度段；`task` 名称本地化；拒绝 / 事件丢弃 >0 高亮；无该段时不显示。

### F-06 错误与空态（核心）

- [ ] **S-06-01** 制造指标命令失败且无旧数据。期望：显示错误 banner 与重试按钮；不显示空表；点击重试可恢复。
- [ ] **S-06-02** 制造刷新失败但已有数据。期望：保留旧数据；隐藏「实时」；显示「数据已过期」；不弹错误遮罩。
- [ ] **S-06-03** 制造零插件快照。期望：显示「暂无 wasm 指标」空态，不当作错误；不显示错误 banner。
- [ ] **S-06-04** 制造宿主 `plugin_list_loaded` 软失败。期望：显示宿主清单告警；状态列落「状态未知」；指标仍展示。
- [ ] **S-06-05** 恢复快照源。期望：错误 / 过期状态自动消失；数据恢复；无需刷新页面。
- [ ] **S-06-06** 检查长插件名 / 长 id / 窄窗口。期望：不重叠、不截断关键字段；表格可滚动。

### F-07 自定义监控面板（需提供方）

- [ ] **S-07-01** 无提供方时查看页头。期望：无页签条、无面板区、无面板错误。
- [ ] **S-07-02** （有测试提供方）确认提供方 manifest 声明 `contributes.monitorPanels: [{id,title,order}]`。期望：监控页出现「运行监控」+ 提供方面板页签，按 order 排序。
- [ ] **S-07-03** 点击提供方面板页签。期望：先卸载旧实例，再装载面板；面板内容可见。
- [ ] **S-07-04** 切回「运行监控」页签。期望：面板实例卸载，主监控页恢复；无双重轮询。
- [ ] **S-07-05** 制造面板装载失败。期望：显示面板错误、面板名与原因，并提供重试；不拖垮主页面。
- [ ] **S-07-06** 提供方撤销注册 / 卸载。期望：页签消失并自动回到主监控页。
- [ ] **S-07-07** 宿主未注入 `mountMonitorPanel` 时点击面板。期望：显示「不支持」提示，不白屏。
- [ ] **S-07-08** 未点击面板页签时观察。期望：面板不预装载；无后台请求 / 轮询。

### F-08 多任务卡片预览

- [ ] **S-08-01** 在宿主多任务卡片查看 Monitor 预览。期望：显示 5 项以内摘要（插件数 / 调用 / Trap / 内存等），只读。
- [ ] **S-08-02** 制造指标不可读。期望：显示「指标不可读」；零插件显示「暂无 wasm」；不显示假数据。
- [ ] **S-08-03** 观察预览行为。期望：只取一次数，不轮询、不写存储、不换发令牌；退出预览后主页面不受影响。

### F-09 移动端监控（核心，真机）

- [ ] **S-09-01** 从移动宿主打开 Monitor。期望：全屏监控页；KPI、筛选、台账可见。
- [ ] **S-09-02** 观察刷新。期望：约 1 秒轮询；手动刷新时才显示按钮加载态；更新时间变化。
- [ ] **S-09-03** 查看台账。期望：按 Trap 降序；行内显示 plugin id、状态、角色；名称 / kind 来自快照 `plugin_meta`；无宿主运行态字段。
- [ ] **S-09-04** 展开 / 收起某行详情。期望：折叠时不渲染详情；展开后指标完整。
- [ ] **S-09-05** 切换过滤、查看错误 / 过期 / 空态。期望：与桌面行为一致；`mobile-` 前缀锚点状态正确。
- [ ] **S-09-06** 查看宿主维度。期望：默认裁掉 `task` 段（按实现）；其他段出现时正确展示。
- [ ] **S-09-07** 若有面板提供方，验证页签与装载 / 卸载。期望：与桌面一致；失败有重试。
- [ ] **S-09-08** 与桌面同一时刻对照 KPI / 自身行。期望：量级一致（允许采样时间差），不出现一侧全零。

### F-10 应用管理服务区（核心）

- [ ] **S-10-01** 在隔离环境（仅 monitor）打开 `/sys/apps`。期望：系统服务分组可见且标题有文案；不渲染空的应用分组标题。
- [ ] **S-10-02** 查看服务卡片。期望：显示 Monitor；不出现卸载按钮。
- [ ] **S-10-03** 查看开关。期望：启用 / 自启两个 switch 在场；自启缺省 `true`。
- [ ] **S-10-04** 在测试环境关闭再开启自启。期望：状态翻转并持久化；服务运行态不受误伤。
- [ ] **S-10-05** 尝试像 L3 应用一样卸载。期望：无入口；不得通过上下文菜单绕过（按宿主服务守卫行为记录）。

## 4. 已知缺口（不纳入通过判据）

| 项               | 现状                                                                | 处理                                      |
| ---------------- | ------------------------------------------------------------------- | ----------------------------------------- |
| 真实自定义面板   | 仓库内没有应用声明 `monitorPanels`，只有测试桩                      | F-07 无提供方时标 `⏭`；可用测试提供方验证 |
| 应用过滤计数     | 「应用」过滤展示所有非服务行（含 unknown），计数只数 `business-app` | 记录不一致，不判失败                      |

| 移动端详情       | 用可展开 `details`，折叠不渲染详情；无宿主运行态 / 名称             | 按实现验证差异                            |
| 采样窗口         | 调用速率图只用本次打开的真实采样，首个采样显示「正在建立基线」      | 不把「暂无曲线」记为失败                  |
