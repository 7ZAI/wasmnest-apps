# File Transfer 端到端功能验证模板

> **模板版本**：v1（2026-10-26）
> **适用对象**：`com.wasmnest.file-transfer`（`apps/file-transfer/desktop` + `apps/file-transfer/mobile`）
> **报告用法**：复制到 `docs/verification/reports/<YYYY-MM-DD>-file-transfer-v<版本>.md`，
> 按 §3 执行；标记口径见 [README.md](README.md) §3.3。
> **真实对端依赖**：传输 / 浏览 / 审批 / 续传均需两台设备在同一网络且完成首连信任。
> 桌面单端 E2E 只覆盖壳层开关；**真实数据流必须按 F-14 做双端人工验证**。

## 3. 验证步骤

### F-01 挂载与主界面（核心）

- [ ] **S-01-01** 从宿主侧边栏打开「文件传输」。期望：主界面可见；顶栏对端、传输队列、设置、刷新、上传动作就位。
- [ ] **S-01-02** 在**无共享目录**的干净环境进入。期望：按空态优先级显示「先设置共享目录」类引导，提供打开设置的入口。
- [ ] **S-01-03** 有共享目录但无在线对端。期望：显示「无在线对端」或「已连接但未共享」的对应空态；刷新 / 上传按钮禁用。
- [ ] **S-01-04** 有对端但未设置下载目录。期望：提示设置下载目录，不开始下载。
- [ ] **S-01-05** 在宿主多任务卡片查看 File Transfer 预览。期望：显示最近对端 / 当前任务等只读摘要；空态诚实；无交互控件。
- [ ] **S-01-06** 确认预览无副作用。期望：不发起连接、不启动传输、不写存储。

### F-02 对端发现与切换（核心）

- [ ] **S-02-01** 点击顶栏设备按钮。期望：展开「附近设备」面板；按钮角标显示已连接数；再次点击或点面板外收起。
- [ ] **S-02-02** 点击「探索发现」。期望：重新扫描同网节点；状态点在已连接 / 连接中 / 在线三态间正确；空态提示同网节点。
- [ ] **S-02-03** 查看对端行。期望：显示短指纹前 8 位、地址；当前设备有「当前设备」标签；不支持传输的节点有「不支持传输」标签；最近可见显示时间。
- [ ] **S-02-04** 对一台未连接对端点击「连接」。期望：进入连接中；成功后设为当前设备；失败时行内显示「对方拒绝 / 无法连接」类原因。
- [ ] **S-02-05** 对当前对端点击「断开」。期望：状态回到在线；相关浏览 / 队列按离线态更新。
- [ ] **S-02-06** 多台对端时切换当前设备。期望：当前标签迁移；目录浏览与传输目标随当前设备切换。
- [ ] **S-02-07** 点击顶栏刷新（在线时）。期望：任务、目录、设备三部分刷新；按钮不误触发或重复入队。
- [ ] **S-02-08** 离线状态点击刷新。期望：按钮禁用，不产生错误弹窗。

### F-03 首连信任（核心）

- [ ] **S-03-01** 用未信任对端拨入。期望：自动弹出信任确认；显示节点名、完整指纹（4 字符分组）、30 秒倒计时。
- [ ] **S-03-02** 点击复制指纹。期望：复制成功并显示「已复制」反馈；内容与展示一致。
- [ ] **S-03-03** 点击接受。期望：信任建立；对端可继续连接 / 传输；本端信任列表出现该设备。
- [ ] **S-03-04** 用另一台未信任设备重复，点击拒绝或关闭。期望：连接终止；发送方看到拒绝原因；本端不新增信任。
- [ ] **S-03-05** 不操作等待倒计时归零。期望：自动拒绝；弹窗关闭；无残留遮罩。
- [ ] **S-03-06** 连续发起多个信任请求。期望：单窗排队展示，不叠加多个弹窗。
- [ ] **S-03-07** 用已信任设备重连。期望：不再弹信任确认（按信任策略直接放行）。

### F-04 远程目录浏览（核心）

- [ ] **S-04-01** 连接活跃对端后进入主界面。期望：自动加载对端共享根清单；显示名称 / 大小 / 修改时间三列。
- [ ] **S-04-02** 双击共享根或目录进入子目录。期望：列表更新；面包屑可点击回退。
- [ ] **S-04-03** 点击顶栏刷新。期望：当前目录重新加载；加载中有状态提示；失败显示「该目录当前不可用」。
- [ ] **S-04-04** 查看空目录 / 对端未设置共享目录。期望：分别显示「此目录为空」「对方尚未设置共享目录」。
- [ ] **S-04-05** 断开对端后浏览。期望：切换为离线空态，不显示过期目录冒充可用。
- [ ] **S-04-06** 查看目录行大小。期望：目录显示「—」而不是 0；文件显示真实大小。
- [ ] **S-04-07** 若对端发来存储权限提示（notice）。期望：桌面当前未渲染该提示（§4）；记录实际行为，不假设有横幅。

### F-05 多选下载（核心）

- [ ] **S-05-01** 在共享根内勾选文件。期望：行高亮；表头复选框支持全选 / 半选；目录不可选。
- [ ] **S-05-02** 在根清单层（未进入共享根）查看选择能力。期望：不可多选 / 下载按钮不可用。
- [ ] **S-05-03** 勾选多个文件，点击「下载所选 (N)」。期望：入队成功后清空选择并展开传输队列；任务数与选择数一致。
- [ ] **S-05-04** 未设置下载目录时下载。期望：引导设置下载目录，不入队。
- [ ] **S-05-05** 制造入队失败（对端断开 / 非法路径）。期望：当前实现仅控制台日志，界面无提示（§4）；记录该诚实边界，不记为通过。
- [ ] **S-05-06** 取消全选。期望：选择清空，按钮恢复禁用。

### F-06 上传（核心）

- [ ] **S-06-01** 点击「发送到手机…」。期望：打开系统多文件选择器；取消选择静默返回。
- [ ] **S-06-02** 选择若干测试文件并确认。期望：成功入队并展开队列；任务出现在「正在发送」。
- [ ] **S-06-03** 对端离线时上传。期望：按钮禁用或 toast 提示无法上传；不生成卡住的任务。
- [ ] **S-06-04** 制造上传失败（对端拒绝 / 文件不可读）。期望：显示业务错误 toast；技术原文只进日志。
- [ ] **S-06-05** 上传超过一个大文件，观察进度与速率。期望：进度、已传/总量、速率、ETA 更新；不跳变。

### F-07 传输队列（核心）

- [ ] **S-07-01** 点击顶栏「传输队列」。期望：面板展开；角标显示任务数；再次点击收起。
- [ ] **S-07-02** 切换四个 Tab：全部 / 正在发送 / 正在接收 / 历史。期望：内容与 Tab 一致；各 Tab 空态明确。
- [ ] **S-07-03** 观察任务卡字段。期望：方向箭头、文件名(+N)、状态 chip、进度、已传/总量、速率、ETA、失败原因按状态显示。
- [ ] **S-07-04** 对传输中的本端任务点击暂停。期望：状态转暂停；速率归零；其他任务不受影响。
- [ ] **S-07-05** 对暂停任务点击恢复。期望：从断点继续；已传字节不回退。
- [ ] **S-07-06** 对失败 / 同名被拒 / 中断任务点击重试。期望：重新入队；状态与进度更新；原因清除或更新。
- [ ] **S-07-07** 对非终态任务点击取消。期望：任务停止并移除活跃列表；对端状态同步（按实现）。
- [ ] **S-07-08** 存在暂停任务时点击「全部继续」。期望：所有可恢复任务恢复；无暂停任务时不显示该入口。
- [ ] **S-07-09** 接收卡：暂停 / 恢复 / 取消；完成后点击「打开本地目录」。期望：操作可用；打开目录定位到文件（下载目录有效时）。
- [ ] **S-07-10** 观察总速率。期望：与各任务速率汇总一致；无任务时为 0 / 不显示。
- [ ] **S-07-11** 检查「删除任务」入口。期望：后端明确 unsupported，UI 无入口（§4）；不调用不存在的能力。

### F-08 历史（核心）

- [ ] **S-08-01** 完成 / 失败 / 取消若干任务后查看历史 Tab。期望：按更新时间倒序；显示文件名、结果 chip、时间、大小、对端名。
- [ ] **S-08-02** 对下载完成记录点击「打开所在文件夹」。期望：打开下载目录并定位；目录失效时给出提示。
- [ ] **S-08-03** 对可重试的失败记录点击「重新排队」。期望：重新入队；历史新增记录；原记录保留。
- [ ] **S-08-04** 点击「清空历史」并确认。期望：仅删除终态记录；进行中任务不受影响；取消不删除。
- [ ] **S-08-05** 制造未知失败码。期望：显示状态文案而非后端原文（桌面收口）；原因可理解。
- [ ] **S-08-06** 检查终态上限。期望：超过 200 条后最旧记录被裁剪（按实现抽样验证，不要求制造 200 条）。
- [ ] **S-08-07** 无历史时查看。期望：显示历史空态。

### F-09 共享目录与设置（核心）

- [ ] **S-09-01** 点击设置。期望：设置面板打开；关闭按钮可收起。

### F-10 入站批审批与通知（核心）

### F-11 移动端浏览与下载（核心，真机）

- [ ] **S-11-01** 打开移动端。期望：默认「传输」Tab；底部三 Tab（传输 / 浏览 / 设备）可见；左右滑动可切换。
- [ ] **S-11-02** 在「设备」Tab 查看对端。期望：在线/离线状态准确；空态有「探索发现」；点击可连接 / 切换。

### F-14 跨端互传闭环（核心，双端）

- [ ] **S-14-05** 传输中强制断开一端网络，再恢复。期望：任务进入可重试 / 中断状态；重试后继续；失败原因正确。

## 4. 已知缺口（不纳入通过判据）

| 项               | 现状                                                                              | 处理                     |
| ---------------- | --------------------------------------------------------------------------------- | ------------------------ |
| 桌面入队失败提示 | 仅控制台日志，无用户提示                                                          | 记录边界，不记为 UI 通过 |
| 桌面设置加载失败 | `loadError` 未渲染                                                                | 记录边界                 |
| 删除任务         | 文案 / 命令声明存在，后端返回 unsupported，UI 无入口                              | 不验证删除任务           |
| 桌面对端 notice  | 桌面未渲染对端存储权限提示                                                        | 不要求桌面出现该横幅     |
| 移动「保存到…」  | 仅 i18n 文案与入队 toast，源码无长按 / 保存位置对话框                             | 功能未实现，不验证       |
| 移动并发数显示   | 重载后可能固定显示 3（`mapWireSettings` 硬编码）                                  | 记录显示缺陷，不判失败   |
| 移动差异         | 无修改时间列、无自定义下载目录、无明文警告、历史无对端名、接收卡显示原因          | 按实现验证差异，不记缺陷 |
| 移动单测         | 移动 composables 主要靠 SDK 仓镜像单测；本仓移动端无单测文件                      | 真机人工为准             |
| 真实传输自动化   | 桌面 / 移动 E2E 均不覆盖真实对端数据流；移动 lane 需 debug APK 的 1423 dev server | F-14 必须人工双端执行    |
