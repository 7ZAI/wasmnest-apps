## 需求描述

穿透方案让全部隧道流量走 127.0.0.1（桌面 peer face 入站 / 移动本地代理出站）。现行豁免判据按环回 IP 判定，会把隧道流量静默豁免/跳过链加密，使 bedcode 固定 `required` 失效。两端判据必须改为**面标记**：peer face / 本地代理流量不享受环回豁免，`required` 下缺链路身份即拒绝。

## 落点 app 与端

机制，双端：

- 能力仓：`wasmnest-server-core/src/link_crypto.rs:968-981`（桌面按源 IP 环回豁免）。
- 平台仓（联动）：`wasmnest-mobile/src/plugin/host_domains/ws.rs:210-239`（移动 WS 域对环回目标跳过）——以本地代理句柄上下文区分隧道流量与真本机流量。

- [ ] 移动 WS 域跳过判据改为代理句柄上下文；本地代理出站流量正常协商 link-crypto，不触发环回跳过。
